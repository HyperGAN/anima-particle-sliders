# Final Boss constant-alpha retest

From the equipped Anima study with its original Vibe12 archive mounted, run this command. It inventories saved RAWs, verifies replay, resumes missing measurements, publishes the sample board and audits its evidence.

```sh
env/bin/python product/research/constant-alpha-retest/run.py --study .
```

This retest measures the original distinct Boss score on both the four search characters and eight ranking characters. The product default for new Final Boss measurements is the working Boss score. [Its alpha search](../post-training/working_search.py) Each frozen RAW receives one constant strength across all ten Euler steps. A completed fit receives a numerical rank when every required ranking judgment is available. Screening and stopped arms retain their observed scores in the diagnostic table. Promotion also requires structural qualification.

The sample label, training ParticleGAN version, replay version, matched OFF image, fixed RAW and scalar search path are retained for each method. The cohort inventory records each original training choice before opening the ranking panel. The archived intensity-only trial is available from the sample page.

[Results and matched samples](../../docs/leaderboard.md)

The publisher and HTTP verifier use loopback ports 8796 and 8765 by default. Set `ANIMA_GALLERY_URL` and `ANIMA_TIMED_GALLERY_URL` to the two gallery origins when serving on a private network.
