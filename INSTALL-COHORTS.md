# Anima installation cohorts

The default source package and separate HNDL build both use ParticleGAN 0.11.1.
See the [default lifecycle](LIFECYCLE.md) and [optional HNDL build](HNDL-CANDIDATE.md)
for installation in separate environments.

The [current ComfyUI installation](COMFYUI.md) and fresh plugin ZIP builds use
the same core and ParticleGAN as the default source package.

The published ComfyUI release bundle retains its recorded inference
dependencies. Use the [previous installation guide](https://github.com/HyperGAN/anima-particle-sliders/blob/791a80a4f38a9b8cb096d719b6758a79325bd7d2/INSTALL-COHORTS.md) and the
exact source checkout it identifies to reproduce older training or release packets.
